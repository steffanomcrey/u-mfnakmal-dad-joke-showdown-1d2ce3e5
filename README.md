A dad-joke writer for make.fun's "Dad Joke Showdown" bounty, $5 in USDC. The program scores a handful of original candidate jokes against the kit's published judge rubric (clean pun first, freshness second, tightness third, punchline at the end fourth, spoken-aloud rhythm fifth) and writes the winner, one joke of at most 200 characters, to `/output/entry.txt`. Standard library only, deterministic, no network.

## Run it

```sh
python3 main.py
```
